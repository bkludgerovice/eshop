# Klubové oblečení BK Ludgeřovice

Interní objednávky klubového oblečení pro členy: https://eshop.bkludgerovice.cz

- `index.html` – celá stránka (adresa backendu je v řádku `const API_URL`)
- `logo.png` – logo klubu
- `fotky/` – ilustrace produktů; odkazy na ně patří do sloupce „Foto URL“ v Google Sheetu

Data, sklad a objednávky běží v Google Sheetu s Apps Scriptem, ne v tomto repozitáři.
